Dissecting Tree of Thoughts: An Ablation Study of ToT Search Algorithms

Jaden Cutinha & Junze Xie · Princeton University

// Overview

Large language models (LLMs) have demonstrated remarkable capabilities across diverse reasoning tasks, yet they often struggle with problems requiring planning, exploration, or backtracking. Tree of Thoughts (ToT), introduced by Yao et al. (2023), addresses this limitation by framing problem-solving as a search over a tree of intermediate reasoning steps. The original ToT method relies on Breadth-First Search (BFS) and Depth-First Search (DFS) — relatively simple algorithms that do not fully exploit accumulated information about the search frontier.

This paper asks: if ToT's improvements over chain-of-thought prompting stem from deliberate search, would more informed search strategies yield further gains? We replace the original BFS/DFS with k-beam A* search — treating ToT as a shortest-path problem using LLM value scores as a heuristic — and Monte Carlo Tree Search (MCTS), treating it as a sequential decision problem with simulated rollouts and UCB-style exploration. All other variables (generation method, evaluation method, proposal completions, value samples) are held fixed so that the search algorithm is the sole independent variable.

// Methods

Experiments were conducted on two standard benchmarks — the Game of 24 and 5×5 mini-crosswords — using a GPT-4o-mini backbone. Puzzles were drawn from fixed index ranges to ensure reproducibility. Each trial logged accuracy, API call count, and wall-clock time. For A*, the max heap size was set to 7 and expansion was capped at 10 counted steps for mini-crosswords. Beam width was k = 5 for A* and BFS. MCTS used n_evaluate_sample = 3 value rollouts.

On the Game of 24, A* significantly outperformed BFS while using a nearly identical number of API calls (89.66 vs 86.24 per trial), demonstrating that heuristic-guided global ordering delivers meaningful gains at no extra cost. MCTS achieved 16% accuracy at only 64.9 API calls per trial — the most efficient configuration. On mini-crosswords, all three methods converged to similar accuracy (~20–26%), because tight search budgets prevent any method from escaping a weak early word choice.

// Takeaways

A*'s advantage on Game of 24 is attributable to its global best-first ordering combined with path-averaged value scores, which systematically allocates search effort toward the most promising trajectories. BFS's strict per-layer pruning loses recoverable paths that would be discovered by a globally ordered frontier. MCTS, by running random rollouts to the horizon and backing up scores as prefix support, gives paths a second chance — explaining why it exceeds BFS but falls short of A*'s systematic ordering. These findings suggest that more informative search is a genuine lever for improving ToT reasoning performance.

Evaluating AI Sentiment Consistency and Market Relevance

Jaden Cutinha · Computer Science, Princeton University, Class of 2028

// Research Question

Can AI reliably interpret ambiguous financial news, and does that interpretation help predict the stock market? This project examines whether leading AI models agree on sentiment and whether their judgments correlate with next-day market movements — addressing a gap between AI sentiment research and practical financial signal generation.

// Methods

Two LLMs — GPT-4o and Llama 3.3 70B Instruct — were tested on 45 ambiguous corporate financial headlines drawn from 2023–2024. Headlines were defined as ambiguous: corporate events with no clearly positive or negative valence. Both models used identical deterministic prompts (temperature = 0), and their sentiment labels (Positive / Neutral / Negative) were compared across the full sample. Labels were then matched to next-day stock returns to evaluate whether AI sentiment aligns with real market behavior. An OLS regression was run with GPT-4o sentiment score as predictor and next-day percentage return as the dependent variable.

The models disagreed on approximately 30% of headlines, indicating that AI financial sentiment is not a fully objective signal. Disagreements were most common for headlines involving strategic shifts and pricing changes, where implication direction is inherently interpretable. GPT-4o sentiment showed a statistically detectable but weak relationship with next-day returns (R² = 0.170, p = 0.206), suggesting the effect size is insufficient for standalone predictive use.

// Conclusions & Implications

LLMs exhibit meaningful inter-model disagreement when classifying ambiguous financial sentiment, indicating that model outputs reflect model-specific interpretation rather than an objective signal. While there is a detectable directional relationship between AI sentiment and next-day returns, it falls short of statistical significance at standard thresholds. These findings suggest that AI sentiment classification should be treated as one noisy input among many, rather than a reliable standalone directional indicator. Future work should scale the dataset, incorporate intraday data, and test finance-specific models — and could explore combining AI sentiment with traditional financial indicators for stronger predictive performance.
