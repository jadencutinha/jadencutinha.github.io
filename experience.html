Summer Resident Fellow

IC3, the Initiative for Cryptocurrencies & Contracts

Jun 2026 to Present

Summer Residency

About the Role

IC3 is an academic consortium studying the science behind blockchains, and the residency puts students alongside researchers working on consensus, cryptography, and mechanism design. My work sits on the economics side of that boundary. A consensus protocol can be provably correct and still fail in practice if the validators running it are paid more to deviate than to comply, so the interesting question is what the incentives actually are once real money is moving through the system. That question is answered with data, which meant building the tooling to read blockchains directly and turn raw transaction histories into evidence about how value flows and who captures it.

Key Contributions

  • Built data extraction and analysis tooling to study incentive compatibility and mechanism design tradeoffs across multiple blockchain consensus protocols, processing on chain liquidity and transaction data from constant product automated market makers.
  • Wrote analysis tooling to quantify maximal extractable value in Ethereum block production, processing on chain transaction data to measure how the ordering of transactions within a block redistributes value and what that means for ordering fairness.

Tech Developer Intern

Sponsors for Educational Opportunity (SEO)

May 2026 to Present

New York, NY

About the Role

The SEO Tech Developer Program is an intensive engineering track that pairs several hundred hours of algorithms and systems instruction with real team delivery under SCRUM. The training half moves fast through data structures, algorithms, and the full software development lifecycle. The building half is where it counts. My team shipped PortfoliU, a portfolio optimization platform that solves Markowitz mean variance problems as convex programs and validates them against a walk forward backtest. I led the backend, which meant owning the optimization engine, the risk models, the market data layer, and the API contract the frontend consumes. The architecture was judged the strongest across every group in the cohort.

Key Contributions

  • Completed 300+ hours of rigorous training in data structures, algorithms, and full stack software engineering, building fluency across the software development lifecycle from design through deployment.
  • Collaborated within SCRUM engineering teams to design, test, and deploy applications integrating Python and Flask backends with MySQL databases, JavaScript interfaces, and external API services.
  • Led backend development of a portfolio optimization platform using FastAPI, async SQLAlchemy, and cvxpy for Markowitz mean variance optimization, recognized for the best architectural design across all groups.

Featured Work

PortfoliU is live at optimal-portfolio-nine.vercel.app with the source on GitHub. A longer write up of the solver, the risk models, and the backtesting engine lives on the projects page.
